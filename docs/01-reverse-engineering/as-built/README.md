# Діаграми «як є» (as built)

Діаграми відновлено з коду на теґу `v0`. Кожна має джерело у вигляді `.puml` (PlantUML) і зображення `.png`, яке можна вставляти у звіт.

| Файл | Що показує | Для чого у звіті |
|---|---|---|
| `backend-components.puml` / `.png` | Компоненти backend: маршрути, middleware, контролери, моделі, пул БД. Контролери з прямим SQL виділено червоним (14 із 21, 196 викликів) | розділ 1 (аналіз архітектури), обґрунтування ADR-003 |
| `checkout-sequence.puml` / `.png` | Оформлення замовлення й оплата: розрахунок суми, перевірка залишку, LiqPay, Google Pay, післяплата, керування статусом. Позначено місця дефектів | розділ 1 (аналіз бізнес-логіки), обґрунтування ADR-004 і ADR-006 |
| `block-registration.puml` / `.png` | Шість місць реєстрації типу блока й два рендерери (React та експорт у HTML) | розділ 1, обґрунтування ADR-002 |
| `block-map.md` | Матриця «тип блока × місце реєстрації», псевдоніми `header` / `footer`, формат JSON блока | додаток до розділу 1 |

Порівняння з діаграмами диплома: `../gap-analysis.md`.

## Як перемалювати

```bash
java -jar plantuml.jar -tpng -Sdpi=110 docs/01-reverse-engineering/as-built/*.puml
```

Потрібні Java і Graphviz (`dot`). Для редагування в VS Code підійде розширення PlantUML.
